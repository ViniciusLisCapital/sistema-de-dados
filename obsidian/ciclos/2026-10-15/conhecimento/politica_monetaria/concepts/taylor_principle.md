# Taylor Principle

**Type:** Stability (determinacy) condition
**Tags:** #taylor-principle #determinacy #interest-rate-rule #new-keynesian

---

## Definition

The condition that an interest rate rule must respond to a permanent rise in inflation by eventually raising the nominal rate more than one-for-one, so that the real rate rises. In the basic New Keynesian model it is what makes the rational-expectations equilibrium locally unique (determinate). It is a property of a rule's coefficients, not a rule itself — not to be confused with the [[taylor_rule]].

## Formal statement

For a rule in which the nominal rate responds to current inflation and the output gap with non-negative coefficients φπ and φy, the equilibrium of the basic NK model is unique if and only if `κ(φπ −1) + (1 −β)φy > 0` (Galí ch. 4, (14); the same condition is (28) in ch. 3). Using the long-run relation between inflation and the output gap implied by the NKPC, the condition is equivalent to the long-run response of the nominal rate to a permanent change in inflation, φπ plus the output-gap response scaled by (1 −β)/κ, being greater than one (Galí's (15)). With φy set to zero it reduces to an inflation coefficient greater than unity.

## When it applies / when it fails

- A rule that tracks the natural rate one-for-one but has no endogenous feedback (`it = rn_t`) is consistent with the optimal outcome but leaves the equilibrium indeterminate: other equilibria exist (Galí ch. 4, (8)–(10)).
- When the condition holds, the feedback terms are never activated in equilibrium: the "threat" of a strong response rules out deviations (Galí ch. 4).
- For a forward-looking rule (responding to expected inflation and output gap) the same condition is needed, (17), plus an upper bound, (18): the central bank must not react "too strongly"; Galí's Figure 4.2 suggests that bound binds only at coefficients well above empirical ones.
- Under an exogenous money growth path in the basic NK model, the equilibrium is determined without it (Galí ch. 3, based on numerical analysis).
