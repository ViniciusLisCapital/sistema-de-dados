USD/BRL Equilibrium Model — Intuition Simulator

Companion to state_space_equilibrium_model.md. Adjust the structural parameters and driver shapes below and watch how an unobserved equilibrium, a mean-reverting deviation, and their sum (the "observed" rate) behave — before any of this is fit to real data.

Updated 2026-07-24 (third pass, same day): added a Constant shape for π_diff and made it the default — a steady, non-widening inflation differential is the more realistic baseline (constant-rate depreciation, a straight-line equilibrium) than the inherited Trend shape, which ramps π_diff's own level and, once accumulated, produces an ever-accelerating (quadratic) equilibrium path instead.

Updated 2026-07-24 (revised same day): equilibrium is now explicitly a relative-PPP path — π_diff, a synthetic inflation-differential proxy, is a rate, so accumulating its raw level each month is the correct construction of a price-level ratio (this is literally how ppp_equilibrium.py builds the real PPP series from IPCA/CPI). Carry, terms-of-trade, and fiscal risk are now all deviation-side regressors, matching bayesian_deviation_model.py's actual fitted structure — an earlier version of this simulator had briefly moved carry into the transition equation using an I(1)/I(0) argument taken out of context; that didn't match how the real model treats PPP as the whole equilibrium and never splits channels this way. Each of the three now enters the deviation equation as a period-over-period change (Δ), not a raw level — feeding a level directly into a difference equation was producing unbounded compounding drift instead of the intended transitory (Step/Pulse) or steady-drift (Trend) effect. φ (reversion speed) defaults to 0.98, matching the ~44-month mean-reversion half-life that model's error-correction follow-up found in real data — it remains the only channel carrying an effect into future months.

120-month horizon (10y)
equilibrium(0) = 100, index units

1 · Measurement

rer(t) = equilibrium(t) + deviation(t)

2 · Transition (equilibrium ≡ relative PPP)

equilibrium(t) = equilibrium(t−1) + γ_ppp·π_diff(t) + η(t)

3 · Deviation (error correction, Δ-driven)

deviation(t) = φ·deviation(t−1) + β_carry·Δcarry(t) + β_tot·Δtot(t) + β_fiscal·Δfiscal(t) + ε(t)

Controls

Transition — equilibrium (≡ relative PPP)
1.0 = strict relative PPP — the nominal rate fully absorbs the inflation differential, month by month. <1 = incomplete pass-through (non-tradables, Balassa-Samuelson); >1 = overshooting.
Unexplained monthly drift in fair value itself, beyond π_diff. Needs "add random noise" on below.
Deviation — error correction (all three channels, Δ-driven)
How much of last month's gap survives. The only channel carrying an effect into future months — the three drivers below act contemporaneously (as Δ), so this is where "residual impact in months forward" actually lives. Default 0.98 ≈ the ~44-month half-life bayesian_deviation_model.py's error-correction follow-up found (weak evidence, P≈89%, not proof) — a real data-derived starting point, not an arbitrary guess.
Negative = higher carry widens the gap this month — the consistent finding in uip_model.py/carry_model.py's simpler regressions (a UIP-violating "wrong sign"). bayesian_deviation_model.py's own multi-channel attempt found no stable sign across samples — try both directions.
The one channel bayesian_deviation_model.py found consistently negative-signed across both its primary and long-sample robustness checks (P(β<0) ≈ 0.82–0.83) — the most reliable of the three, though still not at its 94%-HDI bar.
Positive = worse fiscal credibility (CDS) widens the gap this month. Strongest single-spec sign probability of the three (0.94) — but no longer-sample robustness check exists for it yet, unlike β_tot.
Month-to-month noise in the gap beyond the three channels. Needs "add random noise" on below.

Pure client-side simulation of the three toy equations in state_space_equilibrium_model.md — no real REER, carry, terms-of-trade, fiscal-risk, or price-level data involved (π_diff is a synthetic inflation-differential proxy, not the real IPCA/CPI series ppp_equilibrium.py uses). Built to build intuition for the structural parameters (γ_ppp, φ, β_carry, β_tot, β_fiscal) before any real Kalman-filter estimation is attempted. Rebuilt 2026-07-24 (second revision, same day) to match bayesian_deviation_model.py's actual architecture: equilibrium is explicitly the PPP-consistent path, and carry/tot/fiscal are all deviation-side regressors entered as period-over-period deltas — not split between equations, and not levels. Does not model that same model's own unexplained drift/intercept (~0.2–0.4/month, still an open finding) — a known simplification, not an oversight.
